# 성향분석을 통한 넷플릭스 작품 추천

## 프로젝트 소개
데이콘에서 진행하는 부동산 허위 매물 분류 대회로 해당 데이터를 학습하여 허위 매물을 찾기 위한 최적의 알고리즘을 찾는 경진대회<br>
데이터는
 - ID : 샘플별 고유 ID
 - 매물확인방식
 - 보증금
 - 월세
 - 전용면적
등 총 17개의 컬럼으로 구성되어 있다.

## 프로젝트 기술 소개
 - 라이브러리 : sklearn, SMOTE, matplotlib, KNNImputer
 - 사용 모델 : XGboost, LGBM, RandomForest
 - 모델 최적화 및 평가 : K-Fold, Confusion Matrix, f1_score, SMOTE
 - 인코더 : Label Encoder, KNNImputer
 - 시각화 : matplotlib

## 프로젝트 과정
### 1.인코딩
 - 범주형 변수는 원핫 인코딩을 진행
 - 수치형 변수 및 증감의 경향성이 보이는 변수는 라벨 인코딩을 진행
### 2.결측치
 - KNN Imputer를 적용하여 결측값을 처리
### 3.라벨 불균형
 - SMOTE 적용 및 모델 학습시 파라미터 조정
### 4.불필요한 컬럼 제거
 - 모델의 피처 임포턴스를 통해 하나씩 제거해보면서 교차검증 결과 중 가장 낮은 부분을 차례대로 제거
### 5.모델 학습
 - LGBM Classifier에 K-Fold 교차검증을 통해 일반화 성능 평가

## 프로젝트 결과
### private score 46위
 - public score는 4위로 마감했으나 private score는 46위로 크게 떨어진 것을 확인
 - 피처 임포턴스등을 통하여 컬럼들을 드랍했으나 다중공선성등을 확인하면서 모델에 의존적이지 않은 통계수치도 확인이 필요
 - 결측치들을 KNN Imputer로 대체하였으나 아예 제거한 경우가 더 높은 성능을 내는 것을 확인
 - 라벨이 전반적으로 불균형한데 SMOTE로 오버샘플링을 진행하여 public 데이터에 과적합이 일어나는 것으로 추정
### 결론
 - 라벨 불균형을 단순히 오버샘플링을 활용하여 모델을 학습하니 과적합이 일어난 것을 확인하였고 일반화 성능을 높이기 위해서는 모델의 파라미터 조정 혹은 오버샘플링시 K-Fold뿐만 아니라 다양한 평가 지표 활용이 필요
 - 결측치를 제거 혹은 채워넣기 위한 통계적 기반이 필요
